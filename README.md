## ⚡ About

I design, build and run full-stack products end to end — from data model and API to UI, CI/CD and cloud infrastructure. Most recently I owned **matching, AI pitch-deck analysis, payments, scheduling and infrastructure** at [AdV3nture](https://adv3nture.io), a startup–investor platform serving **200+ active users**, growing from Backend Engineer to Full-Stack & DevOps Engineer.

- 🧱 **Product engineering** — typed Next.js/React frontends with motion and real-time 3D
- 🔌 **Backend systems** — REST APIs, auth & RBAC, payments, real-time messaging, relational data modeling
- 🚢 **DevOps** — containerized deployments, CI/CD pipelines, GCP & Render, PM2 process management
- 🤖 **Applied AI** — LLM features and autonomous agents on the Gemini API; AI-assisted delivery with Cursor & Claude Code

> Most of my production work lives in private client repositories — full case studies are on **[sentack.dev](https://sentack.dev/#projects)**.

`Full-Stack & DevOps Engineer` · `Dec 2025 – Sep 2026` · 🟢 **[Live](https://adv3nture.io)**

### DHM Woodworks & Interiors — Storefront + Admin Platform
`Full-Stack Developer` · `Client project` · 🔒 Private · [Case study](https://sentack.dev/#projects)

Commercial platform for an Addis Ababa furniture and joinery workshop. Storefront opens on an interactive 3D scene showcasing products, timbers and finishes, a before/after portfolio and a journal. A separate admin panel and REST API manage catalogue, content, orders, invoices and site analytics.

`Next.js` `TypeScript` `Three.js` `GSAP` `Tailwind CSS` `Express.js` `Prisma` `MySQL` `Recharts`

### Job Search Agent — Autonomous AI Pipeline
`Full-Stack Developer` · `AI automation` · 🔒 Private · [Case study](https://sentack.dev/#projects)

Always-on agent that scrapes job boards, filters off-target roles, scores the rest against a résumé with Gemini, drafts tailored application emails where every claim is grounded in the résumé, and tracks replies over IMAP — all surfaced in a pipeline dashboard.

`Next.js` `TypeScript` `Node.js` `Prisma` `MySQL` `Gemini API` `Nodemailer` `IMAP`

### SaaS Inventory Tracker — Multi-Role Inventory Management
`Full-Stack Developer` · `SaaS` · 🔒 Private · [Case study](https://sentack.dev/#projects)

Multi-warehouse stock tracking for small businesses: suppliers, categories, inventory valuation, low-stock alerts and a full audit log. Every action secured by JWT authentication and role-based permissions.

`React` `Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `RBAC`

### [Burayu Berhane Kristos Church](https://burayuberhanekristoschurch.com/) — Trilingual Website
